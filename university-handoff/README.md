# University access handoff

Prepared September 23, 2026. Status: planning only; fellowship publication remains suspended pending catalog-quality remediation and the owner's explicit release decision.

This folder describes how the university can give students an official route to the research opportunity database while the lab maintains it on its own website. It can be shared with university web staff as a standalone folder. It contains no database copy or explorer interface.

## Proposed arrangement

The university creates a resource page with a link to the lab-hosted database. Alternatively, university IT creates a university address that redirects to that page. Students find the resource through the university, then use it on the lab website. The lab maintains the catalog and its student-facing page in one place.

A folder is not technically required for this arrangement: the university ultimately needs the approved destination URL and resource description. These documents make the handoff and responsibilities clear before launch.

## Contents

- `university-page-copy.md`: proposed wording for the university's resource page.
- `it-handoff.md`: configuration details, ownership, and the optional university-hosted data approach.
